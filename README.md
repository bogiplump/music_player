# Music Player

Това е десктоп приложение, което позволява зареждането на .mp3 файлове и пускането на музика през тях. Поддържат се и система за акаунти с различни статистики за всеки регистриран акаунт.

За реализацията на приложението са използвани:
- **Backend:** Python 3.x
- **Database:** SQLite
- **GUI:** PyQt6

Стъпки за инсталация и стартиране на проекта:
### 1. Клонирайте хранилището на проекта от GitHub

### 2. (Препоръчително) Създайте виртуална среда чрез venv
    python -m venv venv

    source venv/bin/activate

### 3. Инсталирайте нужните библиотеки
    pip install -r requirements.txt

### 4. Стартирайте приложението
    python -m src.main

### 5. Стартирайте автоматичните тестове
    python -m pytest --cov=src --cov-report=term-missing -v
